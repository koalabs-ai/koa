# 00_inbox — Quick, unsorted capture

Inbox: everything that arrives with no category. Emptied often. Nothing lives here more than a week.

## What it is for

Dropping notes, links, files, quick tasks. No need to decide where it goes. You can capture something without thinking.

## What goes here

- A quick note you're not sure is important yet.
- A link someone shared that you haven't read.
- A file you downloaded and haven't processed.
- A 3am idea with no context.
- An unanswered email, saved as a file.

## What does NOT go here

- Processed files (they go to their final folder).
- Things you've already decided to keep (go to 06_data, 99_docs, 11_work).
- Secrets (go to 10_personal/secrets).
- Large files (go to 08_backups or get discarded).

## Naming

- ISO prefix if urgent: `2026-01-31-topic.txt`.
- No prefix otherwise: `quick-note.md`, `shared-link.md`.
- If you don't know the name, use a timestamp: `2026-01-31T143022Z.txt`.

## For AI agents

- No permanent rules here; an agent can review and sort.
- If it finds orphaned content, it asks where it goes or moves it to 99_docs/concepts.
- Respect what the user added; don't reorganize without asking.
