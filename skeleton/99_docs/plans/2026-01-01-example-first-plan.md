## Context

You just cloned KOA. This plan walks you through the first steps to understand the structure and the tools.

## Expected result

- A clear structure on your machine.
- Your first memories and to-dos.
- Confidence in how to use koa-core.

## Tasks

- [ ] Read AGENTS.md (rules and how agents work here).
- [ ] Run `koa-core doctor` (check that everything is OK).
- [ ] Save a first memory with `koa-core mem add "title" "description"`.
- [ ] Create a to-do with `koa-core todo add "Something I want to do"`.
- [ ] Check naming with `koa-core names --scan` (verify it follows the rules).
